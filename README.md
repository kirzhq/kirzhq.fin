# Finance Tracker

Web application for personal income and expense tracking.

## Stack

- Backend: Java 21, Spring Boot 3, Spring Web, Spring Data JPA, Spring Security
- Frontend: React, TypeScript, Vite
- Database: H2 for local development, PostgreSQL-ready schema via JPA
- API: REST
- Build: Maven for backend

## Local structure

- `backend/` - Spring Boot API
- `frontend/` - React dashboard

## Features planned in this starter

- Transactions list with filters
- Income and expense breakdown
- Monthly cash flow chart
- Category split chart
- Basic REST endpoints for dashboard data
